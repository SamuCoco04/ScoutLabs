# Event taxonomy

This catalogue covers every event type documented by the bundled StatsBomb v1.1 specification and every type observed locally. All 35 documented types were observed. Counts are explicitly split between physical files and the 3,961-valid-match analytical universe.

Provider-supplied `related_events` edges are distinct from locally measured edge resolution. ScoutLabs-inferred adjacency or possession sequences are proposals and were not validated by this audit.

## Important provider relationships

- Pass ↔ Shot: direct `pass.assisted_shot_id` and `shot.key_pass_id` links were all structurally resolved for 75,700 physical pairs.
- Shot ↔ Goal Keeper: provider `related_events` supplies type-paired edges; not every shot is assumed to require the same goalkeeper pair.
- Dribble ↔ Dribbled Past: provider edges are measured in each direction; ScoutLabs must not invent a missing mirror.
- Substitution: the main event player is the player leaving and `substitution.replacement` is the entrant; all 28,044 physical replacement IDs resolved to a known match player.
- Player On / Player Off are separate availability events. A minutes state machine and event order remain planned, not validated.

## Interpretation boundaries

- Event activity is not continuous tracking.
- Pressure is a provider event proxy, not measured defender-to-ball distance over time.
- Ball Receipt* includes intended receipts; it is not direct proof of controlled possession.
- Camera On/off are legacy observed events despite their documented deprecation.
- Related-event edges are provider-supplied; sequence adjacency based on index/possession would be ScoutLabs-derived.
